Objective

The objective of this project is to understand Java Annotations, their purpose, types, built-in annotations, custom annotations, and how annotations are processed at runtime using the Reflection API.

Introduction

Java Annotations are a special form of metadata introduced in Java 5. They provide additional information about classes, methods, constructors, fields, and parameters without changing the program's business logic.

Annotations are widely used in enterprise applications, especially in Spring Boot, Hibernate, JUnit, and Jakarta Validation.

What are Java Annotations?

An annotation is a special interface represented using the @ symbol. It supplies metadata to the compiler, JVM, or frameworks. 

@Override
public void display(){

    System.out.println("Hello Java");

}

Here, @Override informs the compiler that the method overrides a method from the parent class.

Types of Java Annotations

1. Built-in Annotations

  • @Override
  • @Deprecated
  • @SuppressWarnings
  • @FunctionalInterface
  • @SafeVarargs

2. Custom Annotations

Custom annotations are created by developers according to application requirements. 

@interface MyAnnotation{

    String author();

    int version();

}

Built-in Annotations

Java provides several built-in annotations that help the compiler, improve code readability, and reduce programming errors.

1. @Override

The @Override annotation indicates that a method overrides a method from its parent class. 

class Parent{

    public void display(){
        System.out.println("Parent Class");
    }

}

class Child extends Parent{

    @Override
    public void display(){
        System.out.println("Child Class");
    }

}

2. @Deprecated

Marks a class or method as outdated. The compiler displays a warning whenever a deprecated method is used. 

@Deprecated
public void oldMethod(){

    System.out.println("Old Method");

}

3. @SuppressWarnings

Suppresses compiler warnings generated during compilation. 

@SuppressWarnings("unchecked")
ArrayList list = new ArrayList();

4. @FunctionalInterface

Indicates that an interface contains exactly one abstract method. It is commonly used with Lambda Expressions. 

@FunctionalInterface
interface Demo{

    void show();

}

5. @SafeVarargs

Suppresses warnings generated by variable arguments (varargs) methods that use generics.

Meta Annotations

Meta Annotations are annotations that define the behavior of other annotations.

@Retention

Specifies how long an annotation is retained.

Retention Policy Description
SOURCE Available only in source code.
CLASS Stored in the class file but not available at runtime.
RUNTIME Available during runtime through Reflection. 
@Retention(RetentionPolicy.RUNTIME)

@Target

Specifies where an annotation can be applied. 

@Target(ElementType.METHOD)
Element Type Description
TYPE Class, Interface, Enum
METHOD Method
FIELD Variables
CONSTRUCTOR Constructors
PARAMETER Method Parameters

@Documented

Includes the annotation in the generated Javadoc documentation. 

@Documented

@Inherited

Allows child classes to inherit annotations from their parent class. 

@Inherited

Custom Annotations

Java allows developers to create their own annotations based on application requirements. These are known as Custom Annotations. They are commonly used in enterprise applications to provide metadata for classes, methods, and fields.

Example

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)

@interface MyAnnotation{

    String author();

    int version();

}

The above annotation contains two elements:

  • author() – Stores the author's name.
  • version() – Stores the version number.

Using the Custom Annotation

class Student{

    @MyAnnotation(author="Ankitha", version=1)

    public void display(){

        System.out.println("Welcome to Java");

    }

}

Reflection with Annotations

Reflection allows Java programs to inspect classes, methods, constructors, and fields during runtime. It can also read annotation information stored in class files. 

Method method = Student.class.getMethod("display");

if(method.isAnnotationPresent(MyAnnotation.class)){

    MyAnnotation annotation =
        method.getAnnotation(MyAnnotation.class);

    System.out.println(annotation.author());

    System.out.println(annotation.version());

}

Reflection is widely used in frameworks like Spring Boot, Hibernate, and JUnit to process annotations automatically at runtime.

Advantages of Java Annotations

  • Improve code readability.
  • Reduce XML configuration.
  • Provide metadata to the compiler and JVM.
  • Enable runtime processing using Reflection.
  • Simplify framework development.
  • Easy to maintain and reusable.
  • Improve application development speed.

Disadvantages of Java Annotations

  • Can make code complex if overused.
  • Reflection may slightly affect performance.
  • Difficult for beginners to understand custom annotations.
  • Debugging annotation-based applications can be challenging.

Real-Time Applications

Framework Common Annotations Purpose

JUnit @Test, @BeforeEach, @AfterEach Unit Testing
Jakarta Validation @NotNull, @Size, @Email Input Validation

Annotations vs Comments

Annotations Comments
Provide metadata to the compiler, JVM, or frameworks. Provide explanations for developers.
Processed by Java tools and frameworks. Ignored during compilation.
Begin with the @ symbol. Begin with // or /* */.
Can be accessed at runtime using Reflection. Cannot be accessed at runtime.
Used in Spring Boot, Hibernate, JUnit, etc. Mainly used for documentation.

Best Practices

  • Use built-in annotations whenever possible.
  • Create custom annotations only when necessary.
  • Use meaningful annotation names.
  • Choose an appropriate Retention Policy.
  • Use Reflection only when required.
  • Avoid excessive use of annotations.
  • Keep annotation definitions simple and reusable.

Conclusion

Java Annotations are a powerful feature that adds metadata to Java programs without changing their business logic. They simplify configuration, improve code readability, and enable runtime processing through the Reflection API.

Modern Java frameworks such as Spring Boot, Hibernate, and JUnit rely heavily on annotations to build scalable, maintainable, and enterprise-grade applications. Understanding annotations is an essential skill for every Java developer.
