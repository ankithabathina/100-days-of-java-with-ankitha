Objective

Learn Method References in Java, understand their syntax, explore the different types of Method References, and use them to write cleaner and more readable code by replacing simple Lambda Expressions.

Introduction

Method References were introduced in Java 8 as a shorthand notation for Lambda Expressions. They allow developers to reference existing methods using the :: operator instead of writing repetitive Lambda code.

Method References improve readability, reduce boilerplate code, and work seamlessly with Functional Interfaces and the Stream API.

What is a Method Reference?

A Method Reference is a compact way of referring to an existing method without invoking it directly. It is used when a Lambda Expression simply calls an existing method.

Example

names.forEach(System.out::println);

The above Method Reference is equivalent to the following Lambda Expression: 

names.forEach(name -> System.out.println(name));

Syntax

ClassName::methodName

objectReference::methodName

ClassName::new

Types of Method References

  • Instance Method Reference
