Objective Introduction Method Reference Syntax Types

Objective

Learn Method References in Java, understand their syntax, explore the different types of Method References, and use them to write cleaner and more readable code by replacing simple Lambda Expressions.

Introduction

Method References were introduced in Java 8 as a shorthand notation for Lambda Expressions. They allow developers to reference existing methods using the :: operator instead of writing repetitive Lambda code.

Method References improve readability, reduce boilerplate code, and work seamlessly with Functional Interfaces and the Stream API.

What is a Method Reference?

A Method Reference is a compact way of referring to an existing method without invoking it directly. It is used when a Lambda Expression simply calls an existing method.

Example

names.forEach(System.out::println);

The above Method Reference is equivalent to the following Lambda Expression: 

names.forEach(name -> System.out.println(name));

Syntax

ClassName::methodName

objectReference::methodName

ClassName::new

Types of Method References

  • Static Method Reference
  • Instance Method Reference
  • Instance Method of an Arbitrary Object
  • Constructor Reference

1. Static Method Reference

A Static Method Reference refers to a static method of a class. It is used when the required method is declared as static.

Syntax

ClassName::staticMethod

Example

class MathOperations {

    public static int square(int number) {
        return number * number;
    }

}

Function<Integer, Integer> square =
MathOperations::square;

System.out.println(square.apply(5));

Output

25

2. Instance Method Reference

An Instance Method Reference refers to a method of a specific object. The object must already exist before using the Method Reference.

Syntax

objectReference::methodName

Example

Printer printer = new Printer();

Consumer<String> print =
printer::display;

print.accept("Hello Java");

Output

Hello Java

3. Instance Method of an Arbitrary Object

This type of Method Reference refers to an instance method of any object of a particular class. It is commonly used with Collections and the Stream API.

Syntax

ClassName::instanceMethod

Example

List<String> names =
Arrays.asList("java","spring","github");

names.stream()
     .map(String::toUpperCase)
     .forEach(System.out::println);

Output

JAVA
SPRING
GITHUB

4. Constructor Reference

A Constructor Reference is used to create objects by referring directly to a constructor instead of using a Lambda Expression.

Syntax

ClassName::new

Example

Supplier<Student> student =
Student::new;

student.get();

Output

Student Object Created

Method Reference vs Lambda Expression

Method Reference Lambda Expression
Uses the :: operator. Uses the -> operator.
Shorter and cleaner syntax. Requires more code.
Refers to an existing method. Can contain custom logic.
Improves readability. Suitable for complex operations.
Cannot replace every Lambda Expression. Can be used in all Functional Interface implementations.

Advantages of Method References

  • Reduces boilerplate code.
  • Improves code readability.
  • Makes programs easier to maintain.
  • Works seamlessly with Functional Interfaces.
  • Reduces unnecessary Lambda Expressions.
  • Improves code reusability.
  • Frequently used with Stream API and Collections.
  • Encourages cleaner programming practices.

Disadvantages of Method References

  • Cannot replace every Lambda Expression.
  • Requires an existing method with a matching signature.
  • Less flexible for custom business logic.
  • May confuse beginners unfamiliar with the :: operator.

Best Practices

  • Use Method References only when they improve readability.
  • Prefer Method References over simple Lambda Expressions.
  • Use meaningful method names.
  • Choose Constructor References for object creation when appropriate.
  • Combine Method References with Stream API for cleaner code.
  • Avoid replacing complex Lambda Expressions with Method References.
  • Use Functional Interfaces to maximize the benefits of Method References.

Conclusion

Method References provide a concise and elegant way to refer to existing methods in Java. Introduced in Java 8, they reduce boilerplate code and improve readability by replacing simple Lambda Expressions with a cleaner syntax.

They work seamlessly with Functional Interfaces, the Stream API, and the Collections Framework, making them an essential feature for modern Java development. Mastering Method References helps developers write cleaner, more maintainable, and professional Java applications.
