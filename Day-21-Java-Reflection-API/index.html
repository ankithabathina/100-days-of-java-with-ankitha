🎯 Objective

The objective of this project is to understand the Java Reflection API and learn how it allows programs to inspect and manipulate classes, constructors, methods, and fields during runtime. Reflection is an essential feature used by many enterprise Java frameworks such as Spring, Hibernate, JUnit, and Mockito.

Reflection enables Java programs to examine and modify their own structure and behavior while the application is running.

📖 Introduction

Normally, Java classes are accessed during compile time. However, there are situations where the structure of a class is not known until the application is running. The Reflection API solves this problem by allowing Java to inspect classes dynamically.

Reflection belongs to the java.lang.reflect package and provides classes that help developers retrieve metadata about Java classes and interact with them programmatically.

Common Uses

  • Runtime class inspection
  • Dependency Injection
  • Dynamic object creation
  • Framework development
  • Annotation processing
  • Automatic testing
  • Object mapping

🔍 What is Reflection API?

The Java Reflection API is a powerful feature that allows programs to inspect and manipulate classes, interfaces, constructors, methods, and fields while the application is running.

Instead of directly creating objects using the new keyword, Reflection allows Java to create objects dynamically and execute methods without knowing the implementation during compile time.

Reflection is widely used in enterprise frameworks because it provides flexibility and dynamic behaviour at runtime.

Reflection API Features

  • Retrieve class information
  • Access constructors
  • Access methods
  • Access fields
  • Create objects dynamically
  • Invoke methods dynamically
  • Access private members

🏛 Class Object

The Class class is the entry point of the Reflection API. Every loaded Java class has a corresponding Class object that stores metadata about the class, such as its constructors, methods, fields, interfaces, and annotations.

Before using Reflection, we first obtain the Class object of the required class.

Ways to Obtain a Class Object

Method Description
Student.class Obtains the Class object using the class name.
object.getClass() Obtains the Class object from an existing object.
Class.forName() Loads the class dynamically using its fully qualified name.
Class<?> cls = Student.class;
The Class object acts as the gateway to access constructors, methods, fields, and other metadata of a Java class.

🛠 Constructors

Reflection allows developers to inspect all constructors declared inside a class. Constructors can also be invoked dynamically to create objects during runtime.

Retrieving Constructors

Constructor<?>[] constructors = cls.getDeclaredConstructors();

The getDeclaredConstructors() method returns all constructors declared in the class, including private constructors.

Creating an Object Dynamically

Object obj = cls.getDeclaredConstructor().newInstance();

Unlike the traditional new keyword, Reflection creates objects dynamically during program execution.

Method Purpose
getDeclaredConstructors() Returns all constructors
getDeclaredConstructor() Returns a specific constructor
newInstance() Creates an object dynamically

⚙ Methods

Reflection can retrieve information about methods and invoke them during runtime. This capability is heavily used in frameworks such as Spring and JUnit.

Retrieving Methods

Method[] methods = cls.getDeclaredMethods();

The above statement returns all methods declared inside the class, including private methods.

Invoking a Method

Method displayMethod = cls.getDeclaredMethod("display"); displayMethod.invoke(obj);

The invoke() method executes the specified method on the given object.

Method Description
getDeclaredMethods() Returns all methods
getDeclaredMethod() Returns a specific method
invoke() Executes the selected method

📦 Fields

Reflection also provides access to the fields (variables) declared inside a class. Developers can inspect or modify field values during runtime.

Retrieving Fields

Field[] fields = cls.getDeclaredFields();

This method returns all fields declared inside the class, including private fields.

Example Output

  • name
  • age
Method Purpose
getDeclaredFields() Returns all fields
getDeclaredField() Returns a specific field
set() Updates the field value
get() Reads the field value
Reflection makes it possible to inspect and modify object fields dynamically, even when the field names are not known at compile time.

🔒 Accessing Private Members

Normally, private fields and methods cannot be accessed outside their class. However, the Reflection API allows access to these members by using the setAccessible(true) method.

This feature is useful for testing frameworks, dependency injection, and object mapping libraries. However, it should be used carefully because it bypasses Java's encapsulation.

Accessing a Private Method

Method privateMethod = cls.getDeclaredMethod("privateMethod"); privateMethod.setAccessible(true); privateMethod.invoke(obj);

Accessing a Private Field

Field field = cls.getDeclaredField("name"); field.setAccessible(true); System.out.println(field.get(obj));
Note: Avoid using Reflection to access private members unless absolutely necessary, as it can compromise code security and maintainability.

✅ Advantages of Reflection API

  • Allows runtime inspection of classes.
  • Supports dynamic object creation.
  • Enables dynamic method invocation.
  • Useful for Dependency Injection frameworks.
  • Helps build reusable libraries and tools.
  • Supports annotation processing.
  • Essential for ORM frameworks like Hibernate.
  • Simplifies automated testing.

❌ Disadvantages of Reflection API

  • Slower than normal method calls.
  • Breaks encapsulation by accessing private members.
  • Can introduce security vulnerabilities.
  • More difficult to debug.
  • Increases application complexity.
  • Should not be overused in performance-critical applications.

⭐ Best Practices

  • Use Reflection only when necessary.
  • Avoid Reflection in performance-critical applications.
  • Do not access private members unless required.
  • Handle Reflection exceptions properly.
  • Prefer normal Java programming whenever possible.
  • Document Reflection-based code clearly for maintainability.
  • Use Reflection responsibly to preserve encapsulation and security.

🎤 Interview Questions

1. What is the Reflection API?

Reflection is a Java feature that allows a program to inspect and manipulate classes, methods, constructors, and fields during runtime.

2. Which package contains the Reflection API?

java.lang.reflect

3. What is the purpose of the Class class?

The Class class stores metadata about a Java class and acts as the entry point for Reflection.

4. How do you create an object using Reflection?

Object obj = cls.getDeclaredConstructor().newInstance();

5. How do you invoke a method dynamically?

Method method = cls.getDeclaredMethod("display"); method.invoke(obj);

6. Can Reflection access private methods?

Yes. By calling setAccessible(true), Reflection can access private methods and fields.

7. Name some frameworks that use Reflection.

  • Spring Framework
  • Hibernate
  • JUnit
  • Mockito
  • Jackson
  • Gson

8. What are the disadvantages of Reflection?

  • Performance overhead
  • Breaks encapsulation
  • Security concerns
  • Difficult debugging

📝 Conclusion

The Java Reflection API is a powerful runtime feature that enables applications to inspect and manipulate classes dynamically. It plays a crucial role in modern Java development and is widely used in frameworks such as Spring, Hibernate, JUnit, and Mockito.

Although Reflection offers great flexibility, it should be used carefully because it introduces additional runtime overhead and can bypass encapsulation. Understanding Reflection strengthens your knowledge of advanced Java concepts and prepares you for enterprise application development and technical interviews.
