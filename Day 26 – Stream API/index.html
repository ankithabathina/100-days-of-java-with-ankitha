Objective Introduction Stream API Features Creating Streams

Objective

Learn the Java Stream API and understand how to process collections efficiently using functional programming concepts. Explore stream creation, intermediate operations, terminal operations, and real-world applications.

Introduction

The Stream API was introduced in Java 8 to simplify collection processing. It allows developers to perform complex data operations using concise and readable code without modifying the original collection.

Stream API works seamlessly with Lambda Expressions, Method References, and Functional Interfaces to improve productivity and code maintainability.

What is Stream API?

A Stream is a sequence of elements that supports various operations such as filtering, mapping, sorting, searching, and collecting data. Unlike collections, a Stream does not store data; it processes data from a source like a List, Set, or Array.

Syntax

collection.stream()
          .operation()
          .terminalOperation();

Features of Stream API

  • Introduced in Java 8.
  • Supports Functional Programming.
  • Uses Lambda Expressions.
  • Supports Method References.
  • Processes data without modifying the original collection.
  • Supports Sequential and Parallel Streams.
  • Improves code readability and maintainability.

Creating a Stream

Streams can be created from collections, arrays, or the Stream class. 

List numbers =
Arrays.asList(10,20,30,40,50);

numbers.stream()
       .forEach(System.out::println);

Intermediate Operations

Intermediate operations return another Stream and are executed only when a terminal operation is called. They help transform, filter, and process data.

filter()

The filter() method returns only the elements that satisfy the given condition.

Example

numbers.stream()
       .filter(number -> number > 20)
       .forEach(System.out::println);

Output

30
40
50
30

map()

The map() method transforms each element into another form and returns a new Stream.

Example

numbers.stream()
       .map(number -> number * number)
       .forEach(System.out::println);

Output

100
400
900
1600
2500
900
400

sorted()

The sorted() method sorts the elements in ascending order.

Example

numbers.stream()
       .sorted()
       .forEach(System.out::println);

Output

10
20
20
30
30
40
50

distinct()

The distinct() method removes duplicate elements from the Stream.

Example

numbers.stream()
       .distinct()
       .forEach(System.out::println);

Output

10
20
30
40
50

limit()

The limit() method returns only the specified number of elements from the beginning of the Stream.

Example

numbers.stream()
       .limit(3)
       .forEach(System.out::println);

Output

10
20
30

skip()

The skip() method skips the specified number of elements from the beginning of the Stream.

Example

numbers.stream()
       .skip(2)
       .forEach(System.out::println);

Output

30
40
50
30
20

Terminal Operations

Terminal operations produce the final result and terminate the Stream. Once a terminal operation is executed, the Stream cannot be reused.

forEach()

The forEach() method performs an action on every element of the Stream. 

numbers.stream()
       .forEach(System.out::println);

collect()

The collect() method collects Stream elements into a Collection such as a List or Set. 

List result =
numbers.stream()
       .filter(number -> number > 20)
       .collect(Collectors.toList());

System.out.println(result);

Output

[30, 40, 50, 30]

count()

The count() method returns the total number of elements in the Stream. 

long count =
numbers.stream().count();

System.out.println(count);

Output

7

min() and max()

These methods return the minimum and maximum elements from the Stream. 

Optional minimum =
numbers.stream().min(Integer::compareTo);

Optional maximum =
numbers.stream().max(Integer::compareTo);

System.out.println(minimum.get());
System.out.println(maximum.get());

Output

10
50

findFirst()

The findFirst() method returns the first element of the Stream wrapped inside an Optional object. 

Optional first =
numbers.stream().findFirst();

System.out.println(first.get());

Output

10

Matching Operations

anyMatch()

boolean result =
numbers.stream()
       .anyMatch(number -> number > 45);

System.out.println(result);

true

allMatch()

boolean result =
numbers.stream()
       .allMatch(number -> number > 5);

System.out.println(result);

true

noneMatch()

boolean result =
numbers.stream()
       .noneMatch(number -> number < 0);

System.out.println(result);

true

Advantages of Stream API

  • Reduces boilerplate code.
  • Improves code readability.
  • Supports Functional Programming.
  • Processes collections efficiently.
  • Supports parallel processing.
  • Works seamlessly with Lambda Expressions.
  • Does not modify the original collection.

Disadvantages of Stream API

  • Cannot reuse a Stream after a terminal operation.
  • Debugging complex Stream pipelines can be difficult.
  • May not improve performance for small datasets.
  • Requires understanding of functional programming concepts.

Real-Time Applications

Application Usage
Spring Boot Processing collections and REST API data
E-Commerce Product filtering and sorting
Employee Management Searching, filtering, and grouping employees
Report Generation Data aggregation and transformation
Collections Framework Sorting, filtering, and mapping data
